# eClub
Spletna stran za upravljanje nogometnega kluba

Prijavi se v github accound, če delaš v terminalu:
gh auth login

kloniraš:
https: git clone https://github.com/Sedeljsak/eClub.git
ssh: git@github.com:Sedeljsak/eClub.git
GitHub Cli: gh repo clone Sedeljsak/eClub

Vstop v projekt:
cd eClub

Narediti viltulizacijo:
python3 -m venv .venv
source .venv/bin/activate

Nalaganje potrebne pakete/knjižnice:
pip install -r requirements.txt
